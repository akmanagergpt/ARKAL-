# Frontend source root

Phase 1 establishes the workspace only. There is deliberately **no** application
entry point, component, route or dashboard here.

Per `docs/canonical/ARCHITECTURE.md`, every capability phase from Phase 5 onward
delivers its own frontend increment; Phase 27 consolidates navigation and the
Beginner/Professional/Expert modes. Creating a placeholder UI now would be a
fake implementation and is explicitly forbidden by the Build Protocol.
