# Desktop shell root (Tauri 2.x / Rust)

Phase 1 establishes this directory as the canonical desktop root.

**No `Cargo.toml`, `tauri.conf.json` or Rust source is created here.**

Reason, recorded honestly rather than worked around: the Rust toolchain is not
present on the Phase 1 machine (`cargo`, `rustc` and `rustup` all absent). A
manifest written without a toolchain to validate it would be fabricated
configuration — the Build Protocol forbids claiming output that was not
produced or verified.

Per `docs/canonical/IMPLEMENTATION_DEPENDENCY_MATRIX.md` the Tauri desktop shell
is **Phase 28**, whose prerequisite is Phase 27. When that phase begins on a
machine with the Rust toolchain, the workspace manifest and `Cargo.lock` are
generated by real tooling.

Phase 1 status for this root: `UNSUPPORTED` (toolchain unavailable), not PASS.
